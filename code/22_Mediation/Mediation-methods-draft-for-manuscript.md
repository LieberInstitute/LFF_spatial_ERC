# Mediation Methods Draft for Manuscript

## Draft Paragraph

We performed an exploratory Baron and Kenny-inspired mediation screen to evaluate whether candidate gene-expression features attenuate the association between APOE genotype and ERC Oligo.3 expression phenotypes. The predictor was APOE carrier status, represented in the ERC pseudobulk model as a weighted E4-carrier versus E2-carrier contrast across `APOE_syn` genotype groups. The outcome set comprised ERC Oligo.3 genes with baseline APOE-associated differential expression. Candidate mediators were drawn from three biologically motivated sources: APOE-associated ERC astrocyte genes, APOE-associated LC astrocyte-domain genes, and LC neuromelanin-associated genes, with the LC neuromelanin candidates additionally intersected with LC APOE-associated genes for the APOE-to-mediator screen. For each donor set with matched mediator and ERC outcome data, we first fit the baseline model `expression ~ APOE + sex + age + ancestry + mitochondrial expression ratio`, then refit the outcome model after adding one candidate mediator expression vector at a time. Models were fit with limma-voom/edgeR linear modeling, using empirical Bayes moderation and Benjamini-Hochberg false discovery rate adjustment. A mediator/outcome pair was prioritized when the mediator term was significant in the joint model and the APOE effect for the outcome gene was attenuated below the FDR threshold relative to the baseline model. These analyses were used as a mediation-oriented screening framework to nominate APOE-linked cross-cell-type or cross-region relationships, not as definitive causal mediation estimates. Xenium and ligand-receptor analyses were used as downstream orthogonal context for selected mediator/outcome pairs and were not used to define mediation hits.

## Suggested Caveat

Because this workflow tests mediator candidates one at a time and prioritizes attenuation of the APOE coefficient, the results should be presented as mediation-inspired evidence for candidate pathways rather than formal causal mediation estimates. Any final manuscript wording should align the reported donor counts, FDR thresholds, and mediator-source definitions with the exact completed analysis runs.
